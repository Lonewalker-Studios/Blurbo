# Blurbo
Fairly simple 2D game engine. Powered by Simple DirectMedia Layer, OpenGL, Lua and more.
# How to build
Just clone the repository and run ```cmake -S . -B build```. You may sometimes want to specify a generator and architecture like ```cmake -S . -B build -G "Visual Studio 18 2026" -A x64```
# Dependencies
[CMake](https://cmake.org) 3.28 and above.
